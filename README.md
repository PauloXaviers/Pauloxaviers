# 💫 About Me:

Olá, meu nomé é Paulo Henrique.

Sou desenvolvedor Front-End e estudante de Engenharia da Computação, apaixonado por criar aplicações web e mobile modernas, escaláveis e focadas na experiência do usuário. Tenho forte atuação no ecossistema JavaScript, React e TypeScript, construindo interfaces fluidas, responsivas e com alto nível de detalhe visual (pixel-perfect) 

Tenho experiência em estruturar projetos front-end, consumir serviços de backend, integrar ferramentas como Firebase e aplicar bibliotecas de estilo e animação (como Tailwind CSS e Framer Motion). Prezo pela qualidade do código e colaboração em equipe, aplicando metodologias e padrões de mercado como Git Flow e Conventional Commits.
Busco sempre traduzir necessidades complexas em interfaces intuitivas, unindo performance técnica com design de alto impacto.

Principais Competências: React, TypeScript, Ionic, Node.js, Tailwind CSS, Firebase, Git Flow, UI/UX e Desenvolvimento Mobile.
